# Changelog

## 0.1.1

- Keyboard now behaves like the integrated terminal: `Cmd+K` clears, `Cmd/Option + arrows` move by line/word,
  `Ctrl+…` keys go to the shell, and only global shortcuts (`Cmd+P`, `Cmd+Shift+P`, ``Ctrl+` ``…) reach VS Code.

## 0.1.0

- Initial release: free-floating terminals on an infinite canvas, grid arrange, fit to screen,
  zoom and pan, rename and recolor cards, layout saved per workspace.
- English interface with a Brazilian Portuguese translation.
